## 📲 Download the Android app

"Download the latest Hidden-India APK" (https://github.com/Amlan0p/Hidden-India/releases/latest)

1. Open the latest release and download the ".apk" file from Assets.
2. Open the downloaded APK on your Android device.
3. If Android prompts you, allow installation from the browser or file manager you used to download it.
4. Complete the installation and open Hidden-India.

«Install APKs only from a source you trust. Hidden-India is distributed through GitHub Releases and is not necessarily available on Google Play.»

## ✨ Features

- 🗺️ Interactive Maps – Explore destinations with OpenStreetMap and GPS-based location detection.
- 🤖 AI Travel Assistant – Get destination recommendations and travel information.
- ✈️ Smart Trip Planner – Plan personalized journeys with AI assistance.
- 🌐 Multilingual Translator – Communicate across India's diverse languages.
- 📍 Hidden Gems Discovery – Find heritage sites, natural attractions, local food and cultural experiences.
- 🚨 Emergency SOS – Access emergency assistance and discover nearby hospitals and police stations.
- ❤️ Favorites & Itineraries – Save destinations and organize your travel plans.
- 📥 Offline Downloads – Access downloaded travel information without an internet connection.
- 🔐 User Authentication – Personalized accounts and travel experiences.

## 🔐 Environment Configuration

The backend requires environment variables for external API integrations.

Variable| Purpose
"GROQ_API_KEY"| AI functionality
"GEOAPIFY_API_KEY"| Nearby hospitals and police stations

Configure these variables in your backend hosting environment.

Never commit API keys, passwords or other secrets to GitHub.

## 🚀 Development

Android Application

1. Clone the repository.
2. Open the "android/" project in Android Studio.
3. Allow Gradle to synchronize dependencies.
4. Configure the production backend URL.
5. Build and run the Android application.

Backend

cd backend
npm install

Configure the required environment variables, then start the backend using the development command defined in "package.json".
